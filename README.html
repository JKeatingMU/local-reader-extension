Local Reader

A private Chrome extension that turns articles already loaded in the browser into a clean reader view. Its generic readability engine works across publishers without relying on site-specific selectors.

Install once

  1. Open chrome://extensions in Chrome.
  2. Turn on Developer mode in the top-right corner.
  3. Click Load unpacked.
  4. Select the dailymail-reader-extension folder containing this guide. The original folder name is retained so version 1 installations can be reloaded in place.
  5. Open Chrome’s Extensions menu—the puzzle-piece icon—and pin Local Reader.

If version 1 was already loaded, click its reload button on chrome://extensions. Chrome will update it to Local Reader 2.0.0.

Use

  1. Open an article on any ordinary web page and wait for it to load.
  2. Click the Local Reader toolbar icon, or press Option + Shift + R on macOS—Alt + Shift + R elsewhere.
  3. Use the reader controls to change text size, switch between light and dark themes, or print.
  4. Click Original page to return to the normal site.
Private by design. The extension only requests activeTab and scripting. Chrome grants temporary access to the current tab when you click the extension; it has no persistent access to browsing history or other sites.

How it works

Local Reader clones the fully rendered page, uses Mozilla Readability to identify the headline, author and core article content, then sanitizes the result with DOMPurify before displaying it locally. Both libraries are bundled with the extension; no remote code is loaded.

Troubleshooting

  • If Chrome shows WEB on the extension icon, the current tab is not an ordinary web page—for example, it may be a chrome:// settings page.
  • If Local Reader cannot identify a complete article, wait for the page to finish loading and click the icon again.
  • A reader can only process text delivered to the browser. Content absent from the rendered page cannot be extracted.
  • After changing the extension files, open chrome://extensions and click the extension’s reload button.
