Local Chrome extension

Textuary

A browser extension for Chrome and Safari that turns articles into a calm, focused text sanctuary with reading progress, typography controls and private read-aloud.

Install in Chrome

  1. Open chrome://extensions in Chrome.
  2. Turn on Developer mode in the top-right corner.
  3. Click Load unpacked.
  4. Select the local-reader-extension folder containing this guide.
  5. Open Chrome’s Extensions menu—the puzzle-piece icon—and pin Textuary.

If an earlier version is already loaded, click its reload button on chrome://extensions. Chrome will update it to Textuary 2.5.0.

Try in Safari

Safari 26 can load this same folder temporarily for testing. Enable Safari’s developer features, open the Developer settings tab, choose Add Temporary Extension, and select the local-reader-extension folder. See the Safari test instructions for the complete sequence.

Use

  1. Open an article on any ordinary web page and wait for it to load.
  2. Click the Textuary toolbar icon, or press Option + Shift + R on macOS—Alt + Shift + R elsewhere.
  3. Choose a Voice and Speed, then click Read aloud. The same button pauses or resumes, and Stop returns to the beginning. Changes made during playback apply from the next short passage.
  4. Open Reading style to select a theme and typeface or adjust text size, spacing and column width. Textuary remembers these choices locally.
  5. Follow the slim progress bar and estimated time remaining, or click Original page to return to the normal site.
Private by design. The extension requests activeTab and scripting for the article you choose, plus storage to remember reader settings locally. It has no persistent access to browsing history or other sites.

How it works

Textuary compares the rendered page with an inertly parsed copy of the page’s original HTML, then uses the stronger article candidate. This makes extraction more reliable on dynamic sites without publisher-specific rules.

Mozilla Readability identifies the headline, author and core content; DOMPurify sanitizes the result before displaying it locally. Extracted article text is never sent to an external reading or analytics service.

Read aloud uses the browser’s built-in speech support and the voices it exposes from the computer. Textuary divides the article into short passages for reliable playback, highlights the current passage and adds no external speech service.

Troubleshooting

  • If the extension shows WEB on its icon, the current tab is not an ordinary web page—for example, it may be a browser settings page.
  • If Textuary cannot identify a complete article, wait for the page to finish loading and click the icon again.
  • The voice menu is supplied by the browser and operating system; Chrome and Safari may expose different voice lists.
  • A reader can only process text delivered to the browser. Content absent from the rendered page cannot be extracted.
  • After changing the extension files, open chrome://extensions and click the extension’s reload button.
