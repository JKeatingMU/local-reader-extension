# Quiet Front Page TikTok video

This production creates a 21-second, 1080 × 1920 vertical video advertising Quiet Front Page with genuine extension screenshots and a wholly synthetic newspaper homepage.

## Creative structure

1. Crowded newspaper homepage and opening hook
2. One-click transformation into Quiet Front Page
3. Preserved headlines, images and original links
4. Display and compact-layout choices
5. Chrome Extensions Store end card

The narration is generated locally with the installed **Serena (Premium)** Apple voice. Each sentence is rendered separately with controlled pauses for natural cadence. The visual captions carry the central message when the video is viewed without sound. No publisher branding, third-party article text, performance claim, gating claim or advertising-removal claim appears in the creative.

## Build

From the repository root:

```sh
npm run marketing:qfp-tiktok
```

Outputs are written to `dist/marketing/qfp-tiktok/`:

- `qfp-tiktok-v1.mp4`
- `qfp-tiktok-cover.png`
- `qfp-tiktok-contact-sheet.png`
- `voiceover.aiff`
