# Quiet Front Page Privacy Policy

Effective date: 11 August 2026

Quiet Front Page turns the newspaper home or section page selected by the user into a calmer story list. Its privacy model is deliberately simple: page processing happens locally in the browser, and the developer does not collect, receive, retain or sell page content, browsing activity or personal information.

## Information the extension processes

When the user clicks Quiet Front Page or invokes its keyboard shortcut, the extension temporarily processes the URL and rendered contents of that active browser tab. It uses this information only to identify likely story links, headlines, summaries, sections and images and to construct the requested quiet view.

Story links continue to point to the publisher's original pages. Images shown in the quiet view remain hosted by their publishers and may be requested by the browser in the ordinary way. Quiet Front Page does not proxy those requests or send page information to the developer.

## Collection, transmission and storage

Quiet Front Page does not:

- transmit page text, page URLs or browsing activity to the developer
- use analytics, advertising, telemetry, tracking pixels or affiliate links
- create or require a user account
- save reading history, preferences or article lists
- sell or share user data
- block, redirect or modify network requests
- load executable code from a remote server

The generated quiet view exists only in the current tab. Reloading the original page or closing the tab removes it. The browser or publisher may independently retain ordinary cookies, cache entries or website data; Quiet Front Page does not read or manage them.

Quiet Front Page's use of information received from Chrome APIs adheres to the [Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/user-data), including its Limited Use requirements. Information from the active tab is used only to provide the user-facing page-cleaning feature requested by the user.

## Browser permissions

Quiet Front Page requests only these extension permissions:

- `activeTab` provides temporary access to the current page after the user clicks the extension or invokes its shortcut.
- `scripting` allows the packaged Quiet Front Page code to run in that selected tab and construct the quiet view.

The extension does not request persistent access to every website, browser history, downloads, bookmarks or browser storage.
